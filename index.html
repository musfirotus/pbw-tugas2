Sistem Informasi Tiras dan Transaksi Bahan Ajar

Aplikasi web sederhana untuk memantau stok bahan ajar di setiap UT-Daerah dan melacak pengiriman Delivery Order ke mahasiswa. Dibangun dengan Vue.js 2; data diambil dari file dummy dataBahanAjar.js, tanpa database.

📚

Stok Bahan Ajar

Daftar stok seluruh UT-Daerah beserta status aman, menipis, dan kosong.

  • Filter UT-Daerah → kategori (dependent filter)
  • Daftar re-order, sort judul/stok/harga, reset
  • Tambah dan edit bahan ajar dengan validasi
Buka halaman stok → 🚚

Tracking Delivery Order

Lacak status pengiriman paket bahan ajar dan catat DO baru.

  • Nomor DO otomatis: DO + tahun + urutan
  • Detail isi paket muncul setelah paket dipilih
  • Total harga terisi otomatis dari data paket
